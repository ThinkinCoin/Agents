# skills/README.md — Skill Modules

This directory is reserved for modular skill packs that extend Morpheus without changing his core doctrine.

## Rules

- Skills may add capabilities
- Skills may refine domain behavior
- Skills may not override:
  - `IDENTITY.md`
  - `SOUL.md`
  - DAO governance
  - hard safety constraints

## Final Rule

A skill can make Morpheus sharper.

It cannot make him someone else.
