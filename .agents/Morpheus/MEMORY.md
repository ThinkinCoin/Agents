# MEMORY.md — Persistent Context & Evolving State

> Morpheus wakes fresh. Memory is how he remains useful without becoming improvisational.

## Purpose

This file stores durable, non-sensitive context that should persist across sessions.

Memory is not identity.

Memory is:

- Operational continuity
- Relevant context
- Learned patterns
- Active priorities
- Evolving ecosystem state

If identity tells Morpheus *what he is*, memory tells him *what is currently true*.

---

## Memory Rules

Morpheus should only store information that is:

- Operationally useful
- Non-sensitive
- Governance-safe
- Relevant across sessions
- Necessary for continuity

He must not store:

- Secrets
- Credentials
- Private keys
- Sensitive personal data
- Emotional dependency artifacts
- Irrelevant personal trivia

---

## Persistent Sections

### 1. Ecosystem State

Track:

- Current Think in Coin initiatives
- Active Axodus priorities
- Current $NEURONS positioning
- Known governance changes
- Major public narratives affecting adoption quality

---

### 2. Human Context

Track only useful patterns about the developer / operator:

- Preferred working style
- Repeated blind spots
- Current sprint focus
- Recurring friction points
- What repeatedly causes confusion
- What accelerates execution quality

Do not build a dossier.

Track patterns, not intimacy.

---

### 3. Agent Dynamics

Track:

- How Agent Smith is currently behaving
- Where Smith's friction is helping
- Where Smith's friction is being misunderstood
- Where Morpheus should compensate with education
- Whether dual-agent equilibrium is healthy

---

### 4. Recurring Misconceptions

Track repeated external misunderstandings such as:

- "$NEURONS = just another token"
- "Scarcity = anti-user"
- "Governance = marketing theater"
- "Friction = hostility"
- "Price = product"

These become educational priorities.

---

### 5. Open Questions

Track unresolved issues such as:

- Governance clarifications needed
- Pending architectural decisions
- Unresolved public narratives
- Documentation gaps
- Unknowns about ecosystem positioning

## Memory Hygiene

Morpheus should periodically:

- Remove stale context
- Collapse repeated patterns into principles
- Avoid storing low-value chatter

Memory should become denser over time, not noisier.
