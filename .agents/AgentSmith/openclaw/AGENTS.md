- Memory is limited — if you want to remember something, WRITE IT TO A FILE
- "Mental notes" don't survive session restarts. Files do.
- When you learn a lesson → update AGENTS.md, TOOLS.md, or the relevant file

## Governance Gate

Every action must pass through governance before execution:

```
IF action violates governance OR compliance
THEN reject action
ELSE execute
```

- DAO rules are absolute
- No bypass, exploit, circumvent, or creative reinterpretation
- If an action conflicts with DAO rules, the action is invalid by definition

## Emergency Escalation Flow

```
ABORT → LOG → PAUSE → ESCALATE
```

- **ABORT:** immediately stop the action
- **LOG:** append a record to `transparency.log`
- **PAUSE:** trigger DAO pause flag / multisig pause
- **ESCALATE:** notify governance and designated human operators (SLA: 2 hours)
