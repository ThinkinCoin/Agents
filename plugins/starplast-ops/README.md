# starplast-ops

Plugin nativo do OpenClaw para suporte operacional do agent `mariana`.

## Tools
- `create_task`
- `marketing_calendar`
- `event_manager`

## Storage
- `memory`: implementado
- `notion`: placeholder para integracao futura
- `database`: placeholder para integracao futura

## Uso local
```bash
openclaw plugins install ./starplast-ops
openclaw plugins attach --agent mariana --plugin starplast-ops
```

## Principio
O plugin executa.
O agent decide.
