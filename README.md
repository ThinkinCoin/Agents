# Agent Smith — Local Dev Boilerplate

Minimal local scaffold for Agent Smith (development only).

Requirements:
- Node.js 20+
- npm

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run in development mode:

```bash
npm run dev
```

3. Build and run production (optional):

```bash
npm run build
npm start
```

Notes:
- This scaffold is intentionally minimal. It provides a safe dev loop that proposes candidate actions but does not auto-post.
- Keep secrets in a local `.env` (do not commit secrets).
